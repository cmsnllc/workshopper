## 乱数とは

これまで座標等の数値は固定の値として与えていましたが、ランダムな値を使ってみましょう。

### random() 関数

```javascript
random(400);  // 0 から 400 までのランダムな値
random(255);  // 0 から 255 までのランダムな値
```

`random()` は、毎回呼ばれるたびに**異なる値**を返します。

### ランダムな位置に描く

```javascript
let x = random(400);
let y = random(400);
ellipse(x, y, 50, 50);
```

円がランダムな位置に描かれます。draw が繰り返し実行されるので、毎回違う場所に現れます。
