## プログラムの基本

プログラムは基本的に**上から順番に実行されます**。

例えば、以下のプログラムは：

```javascript
function setup() {
  createCanvas(400, 400);
  background(255, 255, 255);
  fill(255, 0, 0);
  ellipse(200, 200, 200, 200);
}
```

1. まず `createCanvas` でキャンバスを作って
2. 次に `background` で背景を白くして
3. 次に `fill` で赤色を指定して
4. 最後に `ellipse` で円を描画する

という順番で実行されます。この順番を変えると、結果も変わってきます。

## コメントを書こう～こっそりメモ～

最初のうちはチンプンカンプンになりがちです。英語で記述しないといけないというのも、私たち日本語話者には難しいポイントです。

大抵のプログラミング言語には**コメント**という構文があり、コメントに書いた内容は実行時に無視されます。`//` スラッシュ 2 個以降はコメントとみなされて、実行時には無視されます。

行末コメントの書き方

```javascript
// これはコメントです
background(255, 255, 255);
```

行末コメントの書き方

```javascript
background(255, 255, 255); // 行末に書いてもOK
```

これからそれぞれの行で何をしているか解説していきます。適宜自分のプログラムにコメントを書いていくとわかりやすくなるでしょう。
