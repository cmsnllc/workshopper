比較の結果は、`println` で表示できます。

```javascript
println(10 > 5);  // true と表示される
println(10 < 5);  // false と表示される
```

### 💡コンピュータの中の true と false

コンピュータの中では、`false` を 0、`true` を 1 として覚えています。0 と 1 だけで数を表すやり方を 2 進数といいます。

でも、プログラムを書くときは「はい」か「いいえ」か、と考えれば大丈夫です。
