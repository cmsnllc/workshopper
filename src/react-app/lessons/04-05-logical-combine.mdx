### 真理値表

この true と false は boolean (ブーリアン)といって、以下のような論理演算ができます。

論理和（OR）

| \|\| | true | false |
|---|---|---|
| **true** | true | true |
| **false** | true | false |

論理積（AND）

| && | true | false |
|---|---|---|
| **true** | true | false |
| **false** | false | false |

これらを組み合わせると以下のような複雑な条件も書けます。

```javascript
let x = 2;
let y = 4;
let z = 5;

// x が0よりも大きいか、y が5よりも大きい
x > 0 || y > 5; // → true

// x は2と等しいかつ、y が4と等しいかつ、z が5と等しい
x == 2 && y == 4 && z == 5; // → true
```
