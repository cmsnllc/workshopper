## 比較演算子と真偽値～○○よりも大きい？小さい？～

### 「はい」か「いいえ」で答えられる質問

「10 は 5 より大きい？」と聞かれたら、答えは「はい」です。

「10 は 5 より小さい？」と聞かれたら、答えは「いいえ」です。

プログラムでは、この「はい」を `true`、「いいえ」を `false` と書きます。

```javascript
10 > 5;  // 10 は 5 より大きい？ → はい   → true
10 < 5;  // 10 は 5 より小さい？ → いいえ → false
```

`true` と `false` は、`10` や `255` と同じ「値」の仲間です。数字はいくらでもありますが、この仲間は `true` と `false` の 2 つしかありません。この 2 つを**真偽値（ブール値、boolean）**といいます。

### 比較演算子

「より大きい？」「等しい？」のような質問を作る記号を、**比較演算子**といいます。

```javascript
let x = 10;

x > 5;   // → true  (x は 5 より大きい)
x < 5;   // → false (x は 5 より小さくない)
x >= 10; // → true  (x は 10 以上)
x <= 5;  // → false (x は 5 以下ではない)
x == 10; // → true  (x は 10 と等しい)
x != 10; // → false (x は 10 と等しくないわけではない)
```

- `>` : より大きい
- `<` : より小さい
- `>=` : 以上
- `<=` : 以下
- `==` : 等しい（**注意**: `=` は代入、`==` は比較）
- `!=` : 等しくない
