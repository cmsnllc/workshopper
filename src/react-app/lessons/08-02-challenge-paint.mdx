## プログラムの解説
mouseClicked は、マウスがクリックされたら｛｝（波かっこ）の内容を実行するものです。また、mouseX と mouseY は特殊な変数で、現在のカーソルの位置を x,y 座標で取得できます。よって、マウスがクリックされたらマウスの位置に丸を描画するプログラムになります。

## 🤔試してみよう④

`background(255, 255, 255);` の行を消すとどうなるだろう？

1. まず、そのまま実行して、キャンバスを何回かクリックしてみよう
2. 次に、`background(255, 255, 255);` の行を消してもう一度実行して、同じようにクリックしてみよう

## 💡なぜこうなるのか考えてみよう

行を消す前と消した後で、何が変わったかな？

答えを見る前に、次の 2 つをヒントに自分で考えてみよう。

- `background` は、どんな命令だったかな？
- `mouseClicked` の中に書いた命令は、いつ実行されるかな？

<Answer>

`background(255, 255, 255);` は、キャンバス全体を白でぬりつぶす命令です。

行を消す前は、クリックするたびに「全体を白でぬりつぶす → 丸を描く」をやり直していました。前に描いた丸は、白でぬりつぶされて消えていたのです。

行を消すと、白でぬりつぶされなくなります。前の丸が残ったまま新しい丸が増えていくので、クリックした場所に絵を描けるようになります。

</Answer>
