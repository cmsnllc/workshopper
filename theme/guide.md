小学生後半から中学生向けの p5.js ワークショップ教材「トライ・やる・DAY」の見た目のルール。ノートにペンで描いたような、あたたかい手描きの紙面をすべての画面で守る。

## 文言

- 子どもに話しかける、やわらかい「です・ます」。命令形や煽り文句は使わない
- ボタンは動作をそのまま書く。実例: `実行`、`停止`、`リセット`、`説明を読み直す`、`次のレッスンへ`
- 絵文字は UI の部品には使わない。レッスン本文の見出しにある絵文字は教材の中身なのでそのまま
- エラーは何が起きたかを先に書く。実例: `エラー: x is not defined`

## 色

- 画面は `paper` の生成り。テーマは Paper の 1 つだけで、ダークモードは持たない
- 文字、枠線、影はすべて `ink`。黒 (`#000`) は使わない
- 面の段差は `paper` → `paper-deep` (沈める) と `paper` → `card` (浮かせる) の 2 つだけ
- `accent` `coral` `leaf` は面を塗る色。その上の文字は必ず `ink` にする。白抜き文字はコントラストが足りないので使わない
- `leaf` は実行、`coral` は停止、`coral-wash` はエラー。色だけで伝えず、必ず文言かアイコンを添える
- `code-*` はエディタと本文のコードブロックで同じ色を使う
- グラデーションで面を塗らない。使うのはドット方眼とマーカー下線の 2 つだけ

## 文字

- 追加の Web フォントは読み込まない。会場の回線に依存しないため、端末に入っている書体を指定するだけにする
- 当日の端末は Chromebook。`sans` は Noto Sans CJK JP が当たる前提で、手描き感は書体ではなく線と形で出す
- 見出しは極太 (900)。本文は 400、小さいボタンと一覧は 500 か 700
- レッスン本文は `lead` の 18px。プロジェクターと小さい画面の両方で読める下限として守る
- コードは `mono` の `code` スタイル。エディタと本文で大きさを揃える

## 余白とレイアウト

- 余白は Tailwind 既定の 4px 単位。`space-2` は `p-2`、`space-5` は `p-5` と同じ数字で書く
- ヘッダー、レッスン一覧 (幅 250px)、本文またはエディタの 3 つで画面を埋める。ページ全体はスクロールさせず、各パネルの中でスクロールする
- 解説ページの本文は最大幅 720px で中央に置く
- エディタページはコードとプレビューを左右に半分ずつ

## 形

- 角は `radius-wobbly` 系のゆがんだ角丸。四隅の値を揃えない。Tailwind では `rounded-wobbly` `rounded-wobbly-lg` `rounded-pill` `rounded-blob`
- 枠線と区切り線は `border-ink` の 2px、色は `ink`。Tailwind では `border-2 border-ink`。1px の細線は使わない
- 浮かせたい部品には `shadow-offset` か `shadow-offset-sm` のずらし影。ぼかした影は使わない
- 押せる部品は押すと影の分だけ右下に沈む
- 飾りはマステ (`.tape`)、マーカー下線 (`.marker`)、ドット方眼 (`.bg-dots`) の 3 つ。1 画面に盛りすぎない
- 破線の枠は「取り消す」系の操作 (リセット) だけに使う

## アイコンと画像

- アイコンは `react-icons` を `ink` 1 色で使う
- レッスンの画像は `public/images/` の写真やスクリーンショット。枠線と影は付けない

## 部品

- Header: ロゴ文字
- LessonList: カテゴリのラベル、章番号バッジ付きの章、選択中のレッスン
- LessonContent: タイトル、本文、コードブロック、真理値表
- ExerciseButton: 解説から演習へ進む大きいボタン
- Toolbar: 実行と停止、リセット、説明を読み直す、次のレッスンへ
- Preview: 実行結果の枠、エラー表示、console 出力
- BlankEditor: 穴埋め演習のコードと入力欄。箱は `radius-wobbly` の枠、空のまま実行されたら破線と `coral-wash`
- Celebration: 正解したときの「正解！」のスタンプと紙ふぶき。動きを減らす設定の端末では紙ふぶきを出さない

部品は Tailwind のクラスで組む。実装は `src/react-app/`。色や角丸を足したいときは `theme/tokens.json` を直して `pnpm run theme` で `theme/dist/theme.css` を作り直す。
